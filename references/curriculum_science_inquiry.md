# 教育部 108 課綱自然科學領域架構與 PISA 2025 探究能力指南

## 一、 108 課綱自然科學領域核心素養指標（國中第四學習階段 自-J）

### A. 自主行動
- **自-J-A1**：能應用科學符號、名詞與基本概念，理解周遭自然現象與科技產物，培養探究興趣與主動學習態度。
- **自-J-A2**：能運用科學思考與探究方法（如觀察、分類、推論、歸納、實驗），處理日常生活或學習情境中的問題。
- **自-J-A3**：能依據探究主題，擬定探究計畫、選擇合適工具進行量測與記錄，並能因應操作結果調整方案。

### B. 溝通互動
- **自-J-B1**：能運用文字、圖表、數據、科學模型等多元表徵，清楚傳達探究過程與結論，並與他人進行理性討論。
- **自-J-B2**：能正確操作常見科學測量工具與資訊科技設備，輔助蒐集與分析數據，並具備辨識偽科學與媒體錯誤報導的能力。
- **自-J-B3**：能欣賞大自然之對稱、律動與秩序美，感受科學理論之簡潔與和諧。

### C. 社會參與
- **自-J-C1**：能從科學證據出發，關切生態保育、環境永續、防災安全等公共議題，建立珍惜資源的生活習慣。
- **自-J-C2**：能與同儕分工合作完成實驗或專題探究，尊重他人不同的觀點與發現。
- **自-J-C3**：能認識科學發展的歷史脈絡及其對人類文明與跨文化的深遠影響。

## 二、 科學探究與問題解決六大歷程 (I1 ~ I6)

| 歷程代碼 | 探究能力階段 | 命題要素與評量重點 | 試題題型範例 |
| :--- | :--- | :--- | :--- |
| **I1** | **審視資訊並界定問題** | 從觀察現象或圖表數據中察覺矛盾、提出可檢驗的科學探究問題或假說。 | 「小明觀察加熱時間與溫度變化，發現升溫速率不同的原因可能是...」 |
| **I2** | **規劃實驗／探究計畫** | 辨識「操縱變因」、「控制變因」與「應變變因」，設計合適的對照實驗。 | 「若欲驗證『反應物接觸面積對反應速率之影響』，下列何者為應控制之變因？」 |
| **I3** | **執行實驗／操作驗證** | 指出儀器操作盲點、讀數視角誤差、安全守則缺失或實驗步驟修正方法。 | 「量筒讀取水銀液面時視線應如何對齊？若指針偏左校準螺絲應如何調整？」 |
| **I4** | **分析與陳述數據** | 報讀折線圖、柱狀圖、散佈圖，將表格轉換為關係趨勢線，計算平均值與誤差。 | 「由圖(一)之 M-V 數據判斷，甲物質與乙物質之密度比為何？」 |
| **I5** | **解釋數據並說明推理** | 結合學科原理解釋實驗數據趨勢，建立推論模型或因果關係鏈。 | 「當小車質量加倍時，由加速度變化推論物體加速度與受力之關係。」 |
| **I6** | **分享與評鑑探究結論** | 評估推論結論是否被充分支持、指出實驗限制並提出具體改進方案。 | 「小華由單次實驗即斷定某結論，其推論過程有何不完備之處？」 |

## 三、 Bloom 認知層次在自然科之運用

1. **記憶（Remember / K1）**：科學名詞定義、符號代號、常見物質熔沸點特性、實驗室安全常規。
2. **理解（Understand / K2）**：解釋物理/化學/生物現象之因果成因、分類物態變化、概念轉換。
3. **應用（Apply / K3）**：使用密度公式、浮力公式、歐姆定律、熱量公式進行具體情境之數據計算。
4. **分析（Analyze / K4）**：剖析實驗流程瑕疵、拆解題組複雜情境、比對圖表多組曲線之差異。
5. **評鑑（Evaluate / K5）**：評判不同實驗設計之優缺點、依據數據支持或駁斥某項科學主張。
6. **創造（Create / K6）**：提出改良版實驗裝置、設計解決生活問題之科學步驟。
